# Markdown Note에 오신 걸 환영합니다 👋

좌측 폴더 트리에서 파일을 선택하고, 가운데에서 작성하면 우측에 **즉시** 반영됩니다.

## 지원하는 문법

### 인라인 스타일
**굵은 글씨**, *기울임*, ~~취소선~~, `inline code`, [링크](https://daou.co.kr).

### 리스트

- 일반 항목
- 또 다른 항목
  - 중첩
- [x] 완료된 작업
- [ ] 할 일

### 순서 있는 리스트

1. 첫 번째
2. 두 번째
3. 세 번째

### 인용

> "작성과 뷰어가 한 세트" — 사용자 요구사항.
> 좌측 룰러에는 현재 라인의 마크다운 종류가 흐리게 표시됩니다.

### 코드 블록

```swift
struct ContentView: View {
    var body: some View {
        Text("Hello, Markdown!")
    }
}
```

### 테이블

| 단축키 | 동작 |
|--------|------|
| ⌘O     | 폴더 열기 |
| ⌘N     | 새 파일 |
| ⌘S     | 저장 |
| ⌘⇧1~4  | 테마 전환 |

### 인라인 HTML

<kbd>⌘</kbd> + <kbd>S</kbd> 로 저장할 수 있습니다.

<details>
<summary>더 보기</summary>

HTML 블록도 그대로 통과시킵니다. <code>&lt;details&gt;</code>, <code>&lt;kbd&gt;</code>, <code>&lt;mark&gt;</code> 등.

</details>
